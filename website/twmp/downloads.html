One file, one double-click. Backs up your server list, adds the TW1MP server and registers the community DirectPlay replacement — all per-user, no admin rights, no UAC. Undo anytime with TW1MP_REMOVE=1.

Text input fix

A known bug on Windows 10/11: typing into text fields (login, chat, CD key) barely works. The tools/tw_textinput_patch.py patch in the repo fixes it for both EXEs, creates a backup and is reversible via --restore.

Go to the repo →
No patch handy? As a stopgap, type your text somewhere else and paste it in with Ctrl+V.

Custom quests & dialogue

For nearly two decades, writing your own Two Worlds quests was considered impossible — the file formats were undocumented. That's over.

New

TW1 Dialog & Quest Creator

Build playable quests (IDs 381–399) with branching dialogue trees, journal entries, objectives and rewards — packaged straight into a .wd mod archive. Pure Python, no dependencies, and it never touches your base game files.
