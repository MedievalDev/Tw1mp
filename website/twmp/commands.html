In-game console

The console of Antaloor

Two Worlds ships with a full developer console. Open it with the ^ key (left of the 1) and type commands straight in.

← Back to the home page

Opening the console & enabling cheats

Open the console with ^. Most game-altering commands only work once cheat mode is active:

TwoWorldsCheats 1
Cheat mode resets every time you restart the game, so you'll need to re-enter it. On the shared server, please keep the cheating to your own single-player sessions rather than ruining someone else's evening — characters with obviously cheated stats can be inspected by the server.

The most useful commands

Case usually doesn't matter. Values in brackets are example parameters.

CommandEffect
TwoWorldsCheats 1Enable cheat mode (required for most of the below).
healRestore health to full.
healHRestore the hero's health.
hitHP (100)Change health points by the given value.
hitMana (100)Change mana points.
AddGold (1000)Add gold.
SetGold (1000)Set gold to an exact amount.
AddExperiencePoints (5000)Grant experience points.
AddParamPoints (5)Add attribute points.
AddSkillPoints (5)Add skill points.
SetStrength (50)Set the strength stat.
AddBasicSkill (name)Add a basic skill.
StartMagicSchool (id)Begin training in a magic school.
ec.AddInventory (name)Put an item into your inventory.
ec.CreateObject (name)Spawn an object in the world.
ec.SetRain (1)Turn rain on or off.
ec.SetSnow (1)Control snow.
ec.SetWind (…)Control wind.
ec.SetDayLength (…)Adjust the length of the day/night cycle.
gamerate (2)Change game speed (2 = twice as fast).
killKill the targeted character.

Loading command files with @

Instead of typing every command by hand, you can have the game run a text file from the game folder in one go — just prefix it with @:

@set.txt

That's how the graphics tuning gets applied, for example. It works with any text file containing one console command per line — handy for your own presets. You'll need to load it again after restarting the game.
